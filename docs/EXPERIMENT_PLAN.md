# Experiment plan: k/l + initial-state sweep, multi-seed stability, failure cases

## The physics question first: what are k and l?

In Lorenz (1960) "maximum simplification", k and l are the wavenumbers of the two
retained Fourier modes (x and y directions). They are **fixed structural
constants of the spectral truncation, not dynamical variables** — they do not
evolve and do not follow any additional physics. Changing them re-parameterizes
the closed-form coefficients:

    a = -l^3 / (k(k^2+l^2)),   b = k^3 / (l(k^2+l^2)),   c = (k^2-l^2) / (2kl)

with ẋ = a·yz, ẏ = b·xz, ż = c·xy. So the correct experiment treats (k, l, IC)
as configuration parameters of the same equation, and no external dataset is
needed (or wanted): references are generated by our own verified solver, which
is the defensible choice for the paper. Every (k, l) system conserves
**E = k⁴x² + l⁴y²** exactly (verified to ~1e-12 over 10 time units) and has
periodic closed orbits; k = l is a degenerate edge case (c = 0, z frozen).

## Branch 1 — `feat/k-l-initial-sweep` (initial values × k × l)

- `scripts/reference_sweep.py` — 27-cell grid (k ∈ {1.5, 2, 3} × l ∈ {0.8, 1, 1.5}
  × 3 ICs). Per cell: DOP853 reference over the training span (npz + 3D figure),
  plus long-horizon physics validation: conserved-quadratic drift, RK4-vs-DOP853
  cross-solver check, FFT dominant period. All 27 cells PASS
  (runs/reference_sweep/manifest.csv).
- `scripts/training_sweep.py` — one PINN run per cell (4x60, 20k Adam + 1k
  L-BFGS), resume-safe, incremental CSV at runs/training_sweep/training_sweep.csv.
  Full grid ≈ 2.5–4 h on CPU; pilot timed at ~5.5 min/run.

**Prerequisite fixed on `fix/reference-k-l-coeffs`** (both branches include it):
the SciPy reference solver silently ignored configured k/l and always integrated
k=2, l=1 — meaning every reference and every training ground-truth for k≠2 was
wrong. One-line fix, strict xfail un-xfail'd, 31/31 stress tests pass.

**Sweep result (27/27 cells converge, RMSE 8e-6 … 1.3e-4 over t ∈ [0,1]):**
1. **The system depends only on the ratio k/l** — coefficients are invariant
   under (k, l) → (λk, λl), confirmed analytically (test in test_stress.py) and
   empirically (cells (2,1) and (3,1.5) reproduce byte-identically). The
   parameter space is therefore 1-D + IC, not 2-D + IC.
2. **Difficulty grows with k/l** — median RMSE ≈ 8e-6 at k/l = 1, 3e-5 at 2,
   6e-5 at 3.75. Near-degenerate k/l = 1 (c → 0, z nearly frozen) is easiest.
3. **High-amplitude ICs are hardest** — IC (−1.0, 0.5, 0.75) produces the worst
   cell (1.3e-4 at k/l = 2.5); consistent with the branch-2 large-IC failure.

## Branch 2 — `feat/multiseed-failure-runs` (worktree: ../lorenz1960-pinn-stability)

**Stability result (5 seeds, 4x60, full budget):** RMSE 1.1e-5 … 2.5e-4 — seed 1
is a ~15x outlier. Single-seed results on this problem are not trustworthy;
the paper must report mean ± std over seeds.

**Hard-tier failure result (20k epochs each arm):**

| case | plain 4x60 | causal-windowed 4x60_win9 |
|---|---|---|
| long horizon t ∈ [0, 13.26] | **2.24 (fails)** | **0.040 (56x better)** |
| large IC (10,10,10) | 19.6 (fails) | 235 (also fails, worse) |
| wavenumber ratio 12 (k=6, l=0.5) | 8.6e-4 (fine) | 2.1e-3 (fine) |
| degenerate k=l=1 (control) | 8e-6 | 5e-4 |

Narrative: plain PINN training genuinely fails at the candidate run's horizon
and is rescued by causal windowing (this reproduces the motivation for the
candidate run); extreme IC amplitude defeats **both** arms at this budget —
do not overclaim causal training; wavenumber ratio alone does not cause
failure on the unit span (it degrades accuracy monotonically, see branch 1).
Caveat for the paper: the causal arm is budget-limited by causal_max_iters=2000
with early advance, so plain-vs-causal RMSE is not budget-matched — report
wall clock alongside.

- `scripts/stability_and_failures.py`:
  - `--stability --preset default|candidate --seeds 0,1,2,3,4` — run-to-run
    spread (mean ± std of final RMSE). default = 4x60 (~8 min/seed on CPU);
    candidate = the win27-causal Colab config (run on Colab).
  - `--failures` — four hard cases × two arms (plain vs causal-windowed):
    long horizon (t ∈ [0,5]), large IC (4,4,4), high wavenumber (k=4, l=0.5),
    degenerate k=l=1. 200-epoch smoke already shows the expected separation
    (e.g. large IC: plain RMSE 8.9 vs causal 0.14).

  of the 200-epoch results (resume would skip them).
