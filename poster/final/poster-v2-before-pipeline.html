The Long-Horizon Problem

Training one network per time window with causal weights cuts the combined RMSE from 2.237 to 6.97×10−5, using only the ODE residual.

  • A full-interval PINN couples all times, yet later states depend on earlier ones.
  • Errors pile up and cannot be undone. Our saved single-network run stalls at RMSE 2.237.
  • Builds on causal training (Wang et al., 2024).

Windowed PINN

  • Each window k gets its own 4×60 tanh network. Windows share boundaries, not parameters.
  • A hard trial solution fixes each initial state by construction, so there is no IC penalty to weight.
  • Each window starts from the previous predicted endpoint and copies its weights as a warm start.
Hard trial solution: exact IC
$\hat{u}_k(t) = u_{0,k} + (t - t_k)\,N_k(t;\theta_k)$
Window handoff + warm start
$u_{0,k+1} = \hat{u}_k(t_{k+1}), \qquad \theta_k \leftarrow \theta_{k-1}$

Training Pipeline

Causal Weighting

  • Each point's weight depends on the accumulated loss at all earlier points, so the network fits early times before late ones.
  • Weights are recomputed every epoch and held fixed (detached) during the Adam step.
Causal weight
$w_{k,i} = \exp\!\Big(-\varepsilon \sum\limits_{j<i} \mathcal{L}_{k,j}\Big)$
Causal loss
$\mathcal{L}_{k,\varepsilon} = \frac{1}{n_k} \sum\limits_{i=1}^{n_k} w_{k,i}\,\mathcal{L}_{k,i}$
advance when min w > 0.99then L-BFGS · unweighted residual mean

Physics Checks

  • Residual MSE: 1.874×10−7 on collocation points, 1.872×10−7 on evaluation points (gap ≈ 1.000).
  • State error and ODE residual stay within 10−5–10−3 along the whole orbit.
  • Values are exactly continuous at all 26 inner interfaces, by construction.
  • The DOP853 reference itself drifts by less than 4×10−10.

Limitations & Future Work

  • Each window after the first starts from a predicted state, so earlier error carries forward and derivatives can jump at interfaces.
  • One seed, one initial state, one coefficient set. No windowed run without causal weights was saved.
  • Next: one-change-at-a-time runs over several seeds, and boundary-value problems.

Novelty

A reusable training algorithm for long-horizon ODE initial-value problems.

  1. Split the horizon into windows with exact ICs.
  2. Train each with staged causal weights + L-BFGS.
  3. Hand endpoint and weights to the next window.
