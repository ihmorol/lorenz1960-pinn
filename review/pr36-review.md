Verdict: changes required before using the complete suite for paper ablations. The reference k/l correction is sound and the 31 stress tests pass locally. The current Colab orchestration and sequential control are not validated end to end.

1. HIGH: sequential control cannot finish, and its loss is mathematically wrong (`scripts/sequential_run.py:57-71,82-87`). A one-window, one-epoch CLI run fails with NameError because replace is not imported. Supplying that import in memory exposes Double input / Float network mismatch. Casting the network to float64 exposes an N×3 prediction being assigned to an N×1 buffer. Independently, autograd.grad(u,t,ones_like(u)) differentiates the sum of the three outputs, not each component: for u=(t,2t,3t), it returns 6 rather than (1,2,3). Broadcasting this into the ODE residual trains the wrong physics. Use the existing componentwise residual implementation, consistent dtype/device, and an N×3 prediction buffer. This script currently stays on CPU and has no intermediate checkpoint or completed-run skip. Add a tiny end-to-end check before spending time on R6.

Retaining the causal schedule routes it to train_windows. That path uses four stages capped at 4,000 steps each, so epochs=40,000 is ignored; checkpoint_every=2,000 is also ignored. Progress is saved only after the sole window completes, including L-BFGS. A disconnect can lose the entire R3 training run. 4. HIGH: Drive durability guarantees exceed the implementation (`scripts/colab_suite.py:49-55,98-120`). There is no sync call after an arm in the step loop; only periodic and final sync exist. A hard runtime termination does not execute finally. copy2 overwrites the Drive destination directly, so interruption can damage the last good backup; the shared size/mtime heuristic can skip same-size but different restored content. Use explicit restore policy, temporary copies plus atomic replacement where supported, and immediate sync after each completed arm. Keep a validated previous checkpoint. A ten-minute sync interval still permits loss of unsynced work. Require mounted, writable Drive when persistence is promised.
