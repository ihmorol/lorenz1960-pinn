# Cross-run historical outputs

These comparison images, architecture-sweep plots, CSV, and generated index are
preserved separately from each experiment. They describe earlier branches and
are not inputs to the selected training pipeline.

The original `index.html` uses paths from the old folder layout and is retained
as an archival snapshot, not a current navigation page. The interpretation of
`figures/precision_floor.png` in the historical Run A/Run B report was later
qualified by the two-branch code audit; the image alone does not establish a
numerical precision floor.
