# Historical run archive

These are unique completed experiments retained for provenance. They are not
loaded by the final training entry point.

- `architecture-sweep/`: nine short-horizon depth/width runs.
- `long-horizon-t10/`: baseline and causal-weighted T=10 runs.
- `full-orbit/`: failed batch float64 and the earlier causal-window result.
- `windowed-causal/`: 512-point and 1,500-point causal candidates.
- `ablations/`: the per-window control paired with the shared-network test.
- `time-marching/`: three explicit time-marching variants.
- `cross-run/`: archived comparison plots and index, kept separate from runs.
