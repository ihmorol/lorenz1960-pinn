# IEEE Figure Asset Index

All copied result figures originate from
`src/fydp2/results/figures/` in the saved run. The new pipeline diagram was
generated from the implemented method and is reproducible with
`make_method_pipeline_figure.py`. PDF files are preferred for the manuscript;
PNG files are provided for drafting and presentations.

## Paper candidates

| Asset | Best paper location | What it evidences | Recommendation |
|---|---|---|---|
| `fig01_pinn_method_pipeline` | Section III | The implemented path from scalar time to MLP output, hard trial solution, autograd derivative, Lorenz right-hand side, residual, and loss | **Required method figure** |
| `fig02_collocation_design` | Section III or supplement | 3,000 fixed Latin-hypercube points, uniformity/spacing checks, and residual norm at training points | Optional; use only if the sampling design needs visual explanation |

| `fig05_solution_vs_reference` | Section V | PINN and DOP853 trajectories for `x`, `y`, `z`, with signed errors | **Primary accuracy figure** |
| `fig06_metrics_summary` | Section V or supplement | MAE, RMSE, and maximum-error bars plus the numeric metric table | Usually replace with a normal IEEE table in the main paper |

## Supporting diagnostics

These files are organized for review and supplementary material. They are not
needed in a compact Section III.

| Asset | Evidence | Caution |
|---|---|---|
| `diagnostic_gradient_diagnostics` | Global/per-layer gradient norms, parameter updates, and loss coupling | Diagnostic only; it does not establish mathematical convergence |
| `diagnostic_error_analysis` | Error growth, error distributions, parity plots, and pointwise relative error | Redundant with the main metric table and solution figure for a short paper |
| `diagnostic_phase_portraits` | `x-y`, `x-z`, `y-z`, and 3-D trajectory projections | The selected short interval is a smooth segment, not evidence of a chaotic attractor or long-horizon behavior |
| `diagnostic_invariant_drift` | Drift in two quadratic invariants of the reduced system, PINN versus reference | Useful for a physics-consistency appendix; not necessary for the method narrative |
| `diagnostic_run_summary` | Legacy three-panel solution/error/loss summary | Keep for project continuity; prefer the numbered figures for the IEEE manuscript |

## Source and metric notes

- `fig01` is a method schematic, not a measured result. Its labels use the
  verified architecture `1-60-60-60-60-3`, hard IC, 3,000 LHS points, and
  Adam's `20,000` iterations with a linear `1e-3` to `1e-4` learning-rate decay.
- `fig02` uses the actual collocation array generated by
  `qmc.LatinHypercube(d=1, seed=0).random(3000)` and the trained residual at
  those points.
- `fig03` panel (d) overlays a reference MSE that is recorded for monitoring;
  the DOP853 trajectory is not used in the training loss.
- `fig04` uses `dense_residual` on the 1,001-point evaluation grid. The black
  dashed curve is the three-component Euclidean norm `||r(t)||_2`; the boxplot
  uses `log10(|r_j|)` for each component.
- `fig05` compares the saved checkpoint with the DOP853 trajectory on the
  separate 1,001-point grid. The reference is a high-accuracy numerical
  trajectory, not an analytical solution.
- The exact parameter count verified from `pinn.pt` is **11,283**.

## IEEE placement and export

1. Cite each figure in the prose before it appears.
2. Put the final caption below the figure and keep the caption responsible for
   explaining the visual, not for making a generalization claim.
3. Prefer the PDF assets for LaTeX/IEEE export. Check that labels remain readable
   at the final column width.
4. The generated figures contain descriptive internal titles. Retain them for
   drafts; for the final manuscript, remove or shorten a title if it duplicates
   the IEEE caption or makes the plot too dense.
5. Do not alter the plotted data to improve visual agreement. Any re-render must
   use the same checkpoint, CSV histories, and DOP853 reference settings.
